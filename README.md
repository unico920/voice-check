# 音声チェック

ナレーション音声を聞きながら、気になったところに秒数つきでコメントを残すツールです。
左に台本、右にプレーヤーとコメント欄が並びます。
`index.html` 1枚で動き、外部のライブラリやインターネット接続は使いません。

![音声チェックの画面](screenshot.png)

## 中身

| ファイル | 内容 |
|---|---|
| `index.html` | ツール本体 |
| `script.txt` | 台本（試し用のサンプル） |
| `audio.mp3` | 音声（試し用のサンプル） |
| `screenshot.png` | この説明書の画像 |
| `LICENSE` | `index.html` のライセンス（MIT） |

サンプルは「3分でわかる織田信長」です。ダウンロードしてすぐ試せます。
読み上げソフトで作った音声なので、ところどころ読み方の怪しいところがあります。コメント機能の練習に使ってみてください。

## 開き方（2通り）

どの方法でも、3つのファイル（`index.html`・`script.txt`・`audio.mp3`）は同じフォルダに置いておきます。

### 1. ダブルクリックで開く（いちばん簡単）

1. `index.html` をダブルクリックしてブラウザで開きます
2. 台本は自動で読めません。画面から `script.txt` を選ぶか、ドラッグしてください
   - 音声はたいてい自動で読み込まれます。読み込まれなかったときは、`audio.mp3` も同じように選ぶかドラッグしてください

ダブルクリック（file://）で開いたページは、ブラウザの安全の仕組みで、同じフォルダの台本を自動で読むことができないためです。

### 2. 自分のパソコンをサーバーにして開く（台本も音声も自動で読み込む）

1. ターミナルで、3つのファイルがあるフォルダに移動して次を実行します
   ```
   python3 -m http.server 8000
   ```
   - Windows は `py -m http.server 8000` を実行してください。動かなければ `python -m http.server 8000` を試してください
2. ブラウザで http://localhost:8000 を開きます
3. 台本も音声も自動で読み込まれます（終わるときはターミナルで Ctrl+C）

## 使い方

1. 再生して、気になるところで止めます
2. 「いま止めた位置にコメント」（または C キー）で、種類を選んでコメントを書きます
   - 種類: 読み間違い / 途切れ / 間・速さ / 声の調子 / その他
3. 直し終わったコメントにはチェックを付けておけます
4. 要らなくなったコメントは ✕ で消せます。誤操作を防ぐため、✕ を2回押すと削除が確定します
5. コメントの位置は、シークバーの上に赤い点で表示されます（チェックを付けた対応済みのものは灰色）
6. コメントをまとめて渡すときは、次の2つが使えます
   - 「書き出す（ファイル）」: `voice-check.json` を保存します。このファイルをツールに読み戻す機能はありません（引き渡し・記録用です）
   - 「コピー」: チャットに貼れるテキスト形式でコピーします

コメントはそのブラウザの中に保存されます（外には送られません）。

保存先は「`index.html` の場所＋台本のタイトル」ごとに分かれます。タイトルが同じ（またはタイトルが無い）台本を同じ場所で開くと、コメントが混ざります。案件ごとに、台本の1行目に別のタイトルを付けてください。

そのほか:

- 音声は mp3 以外（wav / m4a / aac / ogg など）も、画面から選べば使えます（ブラウザが再生できる形式に限ります）
- スマホなど画面が狭いときは、プレーヤーが上、台本が下に並びます
- 毎回ドラッグするのが面倒なら、ChatGPT や Claude などの AI に「アイコンをクリックするだけで開けるようにしたい」「URL を開くだけで使えるようにしたい」と相談すると、手順を教えてくれたり代わりに作業してくれたりします
- インターネット上に置くと台本や音声が他の人から見える場合があります。見られたくないものを使うときは、公開されない場所に置くよう AI に伝えてください

## ショートカット

| 操作 | キー |
|---|---|
| 再生 / 停止 | スペース |
| コメントを書く | C |
| コメントを追加 | Ctrl+Enter（Mac は ⌘+Enter） |
| コメント入力をやめる | Esc |
| コメントの位置にジャンプ | コメントの秒数をクリック |
| 5秒戻る / 進む | ← / → |
| その文から再生 | 左の文をクリック |

再生速度は 0.75x / 1x / 1.25x / 1.5x から選べます。

## 自分の台本と音声で使う

`script.txt` と `audio.mp3` を自分のものに入れ替えてください。

`script.txt` の書き方:

```
# タイトル
0:00.5 1つ目の文
0:03.0 2つ目の文

0:09.7 3つ目の文
```

- 1行目が `#` で始まるとタイトルになります（なくても OK）
- 1行に1文。頭に `分:秒` を書くと、その文をクリックしたときにそこから再生します
- 秒を書かなかった文は、文字数から目安の位置を出します
- 空行で段落を区切ります
- 「分:秒 ＋ 空白」で始まる行は、時刻として扱われます。本文がそのような形で始まる文（例: `3:00 からが本番です`）は、頭に時刻を付けてください
